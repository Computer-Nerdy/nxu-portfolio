## 🛰️ Transmission / About Me

I'm **Harish Ragav V.**, a B.Tech Computer Science student specializing in **Internet of Things (IoT)** at **SRM Institute of Science and Technology, Ramapuram**.

I don’t believe computing belongs solely behind a glass screen. My obsession lies in the **convergence zone** — where microcontrollers process physical telemetry, local neural networks run inference under micro-watt budgets at the edge, and 3D WebGL experiences bring complex hardware systems to life in real-time.

> **Engineering Creed:** I don't just want to know *how* something works — I want to take it apart, probe the buses, rewrite the firmware, push it past rated tolerances, and build my own version from bare silicon and raw bytes.

## ⚙️ Engineering Architecture

```
       [ PHYSICAL WORLD ] ──────► [ SENSORS & ACTUATORS ]
               │                              │
               ▼                              ▼
    [ ESP32 / RASPBERRY PI ] ───► [ EDGE AI / TinyML INFERENCE ]
               │                              │
               ▼                              ▼
    [ LOW-LATENCY FIRMWARE ] ───► [ REAL-TIME 3D WEBGL TELEMETRY ]
```

* **🔋 Edge Autonomy:** Processing intelligence directly on constrained silicon under tight thermal, RAM, and power limits.
* **⚡ Hardware-Firmware Synergy:** Interfacing bare-metal registers, interrupt routines, and communication buses with robust software layers.
* **🕹️ Spatial 3D Telemetry:** Translating physical hardware states into interactive, real-time 3D web experiences using Three.js.
* **🔧 First-Principles Engineering:** Designing and debugging electronics, engine telemetry, and mechanical control systems from scratch.
