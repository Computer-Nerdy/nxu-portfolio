## 🛰️ Overview

An interactive, dark obsidian liquid-glass portfolio built at the intersection of **Embedded IoT, Quantum Circuit Simulations, AI/ML Tooling, and Real-Time 3D WebGL Graphics**.

### ✨ Highlights
* **Interactive 3D ESP32 Stage:** Real-time WebGL rendering of the ESP-WROOM-32 board with 360° free orbit, component diagnostics, and an exploded architectural mode.
* **Cinematic Video Reel:** Smooth 60 FPS GPU-accelerated video playback track calibrated to natural scroll speed.
* **Dynamic Kinetic Physics:** Custom typography engine with 5 distinct text texture packs (*Liquid Amber, Quantum Prism, Cyber Circuit, Plasma Ember, Brushed Titanium*) and velocity-stretching cyber cursor.
* **Real-Time Background Transitions:** Smooth cross-dissolving high-tech background scenery with responsive mouse parallax.

## 🚀 Running Locally

```bash

git clone https://github.com/Computer-Nerdy/nxu-portfolio.git

# Navigate into directory
cd nxu-portfolio

# Start a local HTTP server
python -m http.server 3000
```
Open **`http://localhost:3000`** in your browser.
